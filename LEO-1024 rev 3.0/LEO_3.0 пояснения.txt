- На транзисторах Q2, Q3 резисторах R18,R19, R27, R28 собран level shifter для преобразования уровней сигналов CLK, DATA клавиатуры PS/2 5В в 3,3В RP2040.
- На транзисторе Q1, резисторах R12, R9, R10, R11 светодиоде LED1 собран компаратор 12В. Индикация наличия 12В происходит при входном напряжении 10-12В. 
При напряжении ниже 10В индикация віключается. Величиной резистора R9 можно подобрать прог срабатывания.
- Резисторы R1*, R43* предназначены для подачи внешнего сигнала INT с слотов NEMOBUS. Если такая опция не нужна, резистор R1 заменить перемычкой, а R43 можно не устанавливать. 
- Конденсаторы С1, С2 в цепи задающего генератора 14МГц можно не устанавливать. 
- В видеоконвертере RGB-VGA(HDMI) резисторы R85-R92 должны быть установлены в зависимости от выбранного режима работы VGA или HDMI. Номиналы на схеме указаны для режима HDMI.
Для режима VGA номиналы указаны в примечании. Диод D20 и конденсатор C32 используются только для режима HDMI.
- Контакты слотов NEMO BUS A31, B31 используются для передачи аудио сигналов от устройств подключеных к слотам на аудио разъем компьютера.
Включение/отключение этих сигналов осуществляется перемычками J22 J23. Также контакты этих перемычек могут быть использованы совместно с контактом GND для подачи внешнего
аудиосигнала.На печатной плате нанесен рисунок для правильного подключения.
