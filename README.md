# ZX-Pentagon-LEO-1024K
Clone of the popular computer ZX Spectrum Pentagon LEO 1024K

Added board version 2.3 

Changes were made to the board: 

- added connector for external RGB-VGA converter
- moved MAGIC button

- Version LEO-3 introduces an on-screen display (OSD) for the Gotek drive
-
- <img width="4000" height="3000" alt="IMG_20260921_200620" src="https://github.com/user-attachments/assets/6e3c27e3-a6b2-4444-86be-94f31d6a1fb9" />
and allows Gotek control via USB (or PS/2) keyboard using the PgUp and PgDn keys; however, with minor modifications, this feature can also be enabled on version 2.x models. Proper operation requires specific firmware for both the RP2040 and the Altera chip.
  
-A startup logo
<img width="4000" height="3000" alt="IMG_20260921_200557" src="https://github.com/user-attachments/assets/01bca027-08b1-40ad-9824-ab4bd1afba19" />

and a BIOS have been added;

<img width="4000" height="3000" alt="IMG_20260921_200633" src="https://github.com/user-attachments/assets/c3c49eca-40b5-42af-abd2-abfc41802746" />
the BIOS can be accessed by pressing the F2 key. Users can select (switch) ROM images, toggle the Gotek drive mode (A/B), switch between 1024K and 128K RAM modes, and swap mouse buttons (LR/RL).
A HELP menu explaining key aspects of the computer's operation has also been added; it can be accessed by pressing the F1 key.
